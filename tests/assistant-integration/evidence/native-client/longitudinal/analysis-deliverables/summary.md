# Analysis result

Scores increased faster in the programme group: the estimated slope difference was 1.36 points per visit (95% CI 1.11 to 1.61; p = 9.07e-22).
This corresponds to 5.44 more points of change from visit 0 to 4 (95% CI 4.43 to 6.46).
The person-level sensitivity estimate was 1.36 points per visit (95% CI 1.10 to 1.62; p = 6.58e-15), using each person as the independent unit.
Allowing residual AR(1) correlation gave 1.36 points per visit (95% CI 1.11 to 1.61; estimated phi 0.01).
Because group membership is observational, these are trajectory associations rather than causal effects.

## Limitations

- The observational design does not by itself support a causal programme-effect interpretation.
- The primary estimand summarizes trajectories as linear over visits 0 through 4; the categorical-time comparison diagnoses material departures.
- Mixed-model intervals rely on the specified Gaussian random-effects/residual model and approximate finite-sample t inference.
