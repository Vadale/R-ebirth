## Simplifier disposition

A separate bounded simplifier inspected model-download/loading boundaries and
standalone agent examples. The named validation, transport and filesystem
helpers each protect a distinct contract. Repeated setup in independent example
scripts is intentional. No production refactor or helper extraction was justified.

One concrete test gap was addressed: the existing network-failure test mocked
`fetch_url()` with an already classed error. It covered propagation through
`download_verify()`, but not the real transport adapter's conversion of a thrown
error or nonzero status, partial-file cleanup and timeout restoration.

| Original protection | Disposition / surviving coverage |
| --- | --- |
| Classed fetch failure propagates through `download_verify()` | Original body retained, title made explicit |
| Checksum, corrupt cache, URL collision, public API and registry checks | All original bodies retained |

| Timeout elevation/restoration, higher caller timeout, successful bytes/invisible return | Assertions in those cases plus one success case |

No tests were removed. All remain in the ordinary package test route. The
model/network end-to-end case remains explicitly opt-in and skipped locally.
